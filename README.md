# 快递驿站物流管理系统数据库设计(Courier Station DB System)

## 📌 项目背景与协同声明
本项目是一个团队协作开发的快递驿站核心业务管理系统，旨在解决多服务商（菜鸟、顺丰、邮政等）入驻场景下，快递高频入库、出库、派送、存件取件以及货架动态资源调配的完整物流生命周期管理。

为了保证整个系统数据流转的完备性与可演示性，本仓库保留了系统的完整数据模式（Schema）。**本人在团队中的核心技术职责与独立交付成果为：复杂查询 DQL 编写。（具体源码见 `queries.sql`）**

---

* 使用了标准的 `INNER JOIN` 语法及等价性能优化写法。
* 运用 `COUNT()`、`SUM()`、`AVG()`、`MIN()`、`MAX()` 聚合函数进行数据统计。
* 使用 `COUNT(DISTINCT 列名)` 进行去重计数，以及理解 `COUNT(*)` 与 `COUNT(列名)` 忽略 NULL 值的区别。
* 使用 `GROUP BY` 进行单列或多列（如 `courier_id, STATUS`）的分组数据数据聚合。
* 运用 `HAVING` 子句对分组后的聚合统计结果进行二次条件过滤。
* 运用 `ORDER BY ... DESC` 对查询结果进行多字段或单字段的升降序排列。
* 嵌套使用 `WHERE` 子句实现返回单值的标量子查询。
* 运用 `IN` / `NOT IN` 关键字实现返回多行数据的多值子查询。
* 运用 `EXISTS` 和 `NOT EXISTS` 关键字实现高效的相关/关联子查询，用于检测记录的存在性。
* 运用 `FROM` 子查询（将内层查询结果作为派生表/衍生表）来进行外层的多层数据状态统计。


## 💻 技术栈与运行环境
* **数据库引擎**：MySQL 8.0
* **核心文件说明**：
    * `schema.sql`：数据库表结构及索引定义
    * `data.sql`：基础模拟数据插入
    * `queries.sql`：业务核心 SQL 语句
